# 🧳 TRAVELREADY – Info Persiapan Traveling

> **“Siapkan Perjalananmu, Nikmati Perjalanannya.”**

Website informasi dan persiapan perjalanan/traveling yang dirancang sederhana, elegan, modern, dan fungsional dengan **3D travel illustrations** dan palet warna **Deep Maroon & White**.

---

## 🎨 Palet Warna & Visual Style
- **Deep Maroon**: `#7A1F2B`
- **Maroon Accent**: `#9B3040`
- **Light Maroon**: `#F4E6E8`
- **White / Off-White**: `#FFFFFF` / `#FAF8F8`
- **Dark Text**: `#222222`
- **Typography**: `Poppins` (Google Fonts)

---

## ✨ Fitur Utama
1. **Hero & Intro**: Tagline elegan, button CTA, quote banner, & 3D suitcase illustration.
2. **Checklist Barang**: Custom interactive checklist, filter kategori, progress bar maroon smooth, indikator status, & tombol reset.
3. **Dokumen Perjalanan**: Panduan dokumen domestik & internasional + modal konfirmasi interaktif.
4. **Packing Guide**: rekomendasi barang otomatis berdasarkan durasi (`1-3 Hari`, `4-7 Hari`, `> 7 Hari`) & jenis destinasi (`Pantai`, `Gunung`, `Kota`).
5. **Transportasi**: Pilihan 4 moda transportasi (Kereta, Bus, Pesawat, Mobil) dengan card interaktif, highlight border maroon, & informasi detail.
6. **Budget Perjalanan**: Kalkulator estimasi biaya perjalanan interaktif dengan animasi angka counter dan format Rupiah (`Rp 2.500.000`).
7. **Travel Planner**: Form rencana trip dengan kalkulasi durasi hari & summary card output.

---

## 🚀 Cara Menjalankan Project

### Opsi 1: VS Code Live Server (Direkomendasikan)
1. Buka folder project di **VS Code**.
2. Klik kanan pada `index.html` dan pilih **Open with Live Server**.

### Opsi 2: Node.js Dev Server
Jalankan perintah berikut di terminal:
```bash
npm run dev
# atau
npm start
```
Website akan otomatis terbuka di browser pada alamat `http://localhost:3000`.
